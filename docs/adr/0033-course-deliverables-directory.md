# 课程交付物目录：迁入 `docs/` 并统一英文目录名

- **状态**：已接受（2026-10-12，所有者指令触发）
- **编号说明**：接续现有最大编号 `0032`；`0029`~`0031` 历史上未成文，不复用。

## 1. 背景

课程实验 1（需求分析文档）的交付包一直放在**仓库根目录**的中文目录 `需求分析文档/` 下。
实验 2（软件设计文档）要求与实验 1 同目录管理；且所有者要求：

1. 项目里存放这些文件的**目录最好用英文**（文档可用中文文件名）；
2. 根目录下的「需求分析文档」迁到 `docs/` 下新设的一个目录；
3. 实验 2 的设计文档也放到该目录。

按本仓库既有规则（"新目录的建立必须先在 ADR 中说明理由"，`.codebuddy/rules/project-conventions/RULE.mdc` §目录约定），本 ADR 登记该目录决策。

## 2. 驱动因素

| # | 因素 | 说明 |
| --- | --- | --- |
| 1 | 课程要求 | 实验 2 的任务书要求设计文档与需求基线（实验 1）互相可追溯；两代交付物同目录管理最直接 |
| 2 | 仓库卫生 | 交付包放在仓库根，与 `src/`、`Makefile`、`pyproject.toml` 等工程文件混排；`docs/` 才是文档的归处 |
| 3 | 工具链兼容 | 中文目录名在跨平台（Windows / CI / 打包脚本）下反复出问题；目录名英文、文档名中文是既有的语言约定（代码/标识符英文，文档中文）的延伸 |
| 4 | 打包事故的教训 | 实验 1 v1.3 的打包曾把 `.git` 一并打包（体积 + 凭据泄露面），已通过"排除 `.git` + UTF-8 文件名 + 在全新解压目录实跑校验"修正；交付物归位到 `docs/` 后，**不再需要为课程交付而打包整个目录**，该类事故的触发面随之消失 |

## 3. 候选方案

| 方案 | 内容 | 结论 |
| --- | --- | --- |
| A | 留在仓库根，中文目录名不变 | ❌ 与驱动因素 2/3 冲突；实验 2 还要再建一个中文目录 |
| B | 并入 `docs/design/` 或 `docs/requirements/` | ❌ 交付物是**课程工件**，与项目内部设计/需求文档的维护节奏、读者、权威源关系不同；混放会制造"哪份是权威"的歧义 |
| **C（采纳）** | 新建 `docs/course-deliverables/`：`experiment-1-requirements/`（实验 1 包，10 个 md）+ `软件设计文档.md`（实验 2）+ 目录 README | ✅ 目录英文、文档可中文；与 `docs/` 其它子目录平级且互不修改 |
| D | 新建中文目录 `docs/课程交付物/` | ❌ 直接违反所有者"目录用英文"的要求 |

## 4. 决策

1. 新建 **`docs/course-deliverables/`** 作为课程交付物唯一存放处；
2. 实验 1 包整体迁入 **`docs/course-deliverables/experiment-1-requirements/`**（用 `git mv`，保留历史）；
   实验 2 设计文档放 **`docs/course-deliverables/软件设计文档.md`**；
3. **目录名一律英文**；文档文件名可用中文（延续"代码英文、文档中文"约定）；
4. 交付物**只读取**项目既有材料，**不回写** `docs/` 其它文档；冲突以项目内部文档为权威；
5. 搬迁导致的**包内相对链接**（指向 `.codebuddy/`、`docs/devlog/` 的 4 处）随迁修正，其余内容一字不改。

## 5. 后果（含负面）

**正面**：交付物归位；目录名跨平台安全；不再需要为交付打包（消除 `.git` 误打包这一类事故的触发面）；
两代交付物同目录、编号可追溯。

**负面 / 代价**：

1. 实验 1 包内的 4 处相对链接需修正（`../.codebuddy/...` → `../../../.codebuddy/...`；
   `../../docs/devlog/...` → `../../devlog/...`）——**改了已交付工件的内容**，故只改"因搬迁必然失效"的导航链接，
   命令示例与历史记录（如 `mermaid_check.py 需求分析文档`）**原样保留**，新命令写在新目录 README；
2. 新增一处需要维护的索引（本目录 README + `docs/README.md` + 本 ADR 索引三处登记，漏登记会被读成"文档不存在"）；
3. `docs/` 下多一个顶层目录，目录总数 +1（本 ADR 即其理由登记）。
