## 约定

1. **需求基线**：实验 2 设计文档沿用实验 1 的需求编号（`REQ-<模块>-<序号>`，49 条），编号未改；
   变更说明见设计文档 §13。
2. **与项目内部文档的关系**：交付物**只读取**项目既有材料（`docs/` 树）作为依据，
   **不回写、不覆盖**项目内部文档；字段级与决策的权威源在 `docs/design/` 与 `docs/adr/`。
3. **目录命名决策**：见 [ADR-0033](../adr/0033-course-deliverables-directory.md)。
4. **图表自检**（实验 1 包 + 实验 2 文档）：

```bash
python3 .codebuddy/skills/diagram-authoring/scripts/mermaid_check.py docs/course-deliverables
```
