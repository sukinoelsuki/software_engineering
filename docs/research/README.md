# 调研与实验笔记

本目录存放**前沿 AI 生态的调研与实验结论**，是本项目"研究性"的主要证据来源。

---

## 收录范围

- 上游项目与论文的调研（架构、实现、局限）
- 技术方案的可行性验证
- 性能对比实验
- 攻击面与防御手段调研
- **失败的探索**（同等重要，必须收录）

---

## 笔记模板

```markdown
# <标题>

- 日期：YYYY-MM-DD
- 关联：Issue #N / ADR-NNNN
- 时间盒：≤ N 天（实际使用：N 天）
- 状态：已完成 / 已收敛（未达目标）/ 已放弃

## 1. 研究问题

<可证伪、可回答的问题。反例："研究一下 XX 好不好用"。>

## 2. 现状扫查

<相关项目/论文/文档的现状。每条必须给出出处：
 仓库路径 + 提交哈希，或 URL + 访问日期。>

## 3. 方法

<调研 / 原型 / 受控实验；环境、工具、数据、参数。>

## 4. 结果与数据

<原始数据、命令、观测结果。失败结果也要写。>

## 5. 结论

<明确结论，标注置信度：高 / 中 / 低，并说明依据强度。>

## 6. 对本项目的影响

<这个结论会怎样改变我们的设计或计划？若没有影响，说明为什么仍值得记录。>

## 7. 待验证项

<仍不确定的部分，以及验证方式。>
```

---

## 写作要求

1. **结论必须标注置信度**，并说明依据（实测数据 / 官方文档 / 二手资料 / 推测）。
2. **禁止把推测写成结论**；不确定的内容标注 **【待验证】**。
3. 实验类必须记录：环境、命令、原始数据（可在 `reports/` 中归档附件）。
4. **失败结论必须收录**。它防止未来重复踩坑，是研究过程的真实记录。
5. 引用上游内容必须给出出处（路径 + 版本/提交，或 URL + 访问日期）。
