# 提案目录

本目录存放**立项级与大方向级**的提案。与 ADR 的分工：

| 类型 | 回答的问题 | 特点 |
| --- | --- | --- |
| **提案（本目录）** | "有哪些选择？各自代价是什么？" | 调研与论证过程，可保留未采纳的选项与依据 |
| **ADR（[`../adr/`](../adr/)）** | "最终选了什么？为什么？" | 决策结论，短小、只增不改 |

一般流程：**先写提案 → 决策后写 ADR → 提案保留作为论证依据。**

## 命名与格式

- 文件名：`NNNN-<slug>.md`，编号四位递增。
- 结构建议：
  1. **问题与目标**
  2. **约束条件**（时间、硬件、能力、外部要求）
  3. **评估标准与权重**
  4. **候选方案**（每个含：定位、可做增量、优势、风险、可行性）
  5. **对比矩阵**
  6. **推荐与理由**
  7. **待确认信息**
  8. **下一步**

- 事实性陈述必须给出出处；不确定的内容标注 **【待验证】** 并写明验证方式。
