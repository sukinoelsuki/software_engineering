#   否则引用与结论会随上游漂移而失效。升级参考资料时改这里，并记录到 devlog。
#
# 【许可证】
#   全部为 MIT 或 Apache-2.0，允许内部参考与引用。本清单**只做阅读用**，
#   不分发、不再许可、不修改，故不触发额外的合规义务。
#   引用其代码/设计时仍须按项目规范注明出处（路径 + 提交 SHA）。

# 【体积】
#   浅克隆实测合计约 447 MB（含 .git，保留 .git 以便追溯固定提交）。

#   若需精简镜像，删除对应行即可（端侧三项为优先保留项）。

# 【端侧优先】
#   本项目面向低资源/离线环境，因此**端侧实现比大型实现更有参考价值**：
