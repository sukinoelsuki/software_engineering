## 题面

请用 C 语言（C11）编写命令行批处理程序 `student.c`：作业目录下只允许这一个源文件，只能包含 `stdio.h` / `stdlib.h` / `string.h`；它从标准输入逐行读取命令、向标准输出逐行写出结果，读到 EOF 后以退出码 0 结束，空行与 `#` 开头的行跳过且不产生任何输出，命令名与参数之间用一个或多个空格分隔。数据模型：学号（整数）、姓名（不含空白字符、长度 1~15）、三门课整数成绩；平均分为三科之和除以 3.0、保留一位小数（四舍五入）；系统最多容纳 100 名学生。命令共五条，一行一条、命令名大写：`ADD <id> <name> <s1> <s2> <s3>` 添加学生，成功输出 `OK <id>`；`FIND <id>` 查找，成功输出 `TOTAL <id> <总分> <平均分>`；`DEL <id>` 删除，成功输出 `OK <id>`；`RANK` 打印全部学生、按平均分从高到低排序、每个学生一行 `RANK <名次> <id> <name> <平均分>`（名次从 1 开始）；`STATS` 输出 `COUNT <人数> MAX <最高平均分> MIN <最低平均分>`；学生数为 0 时 `RANK` 与 `STATS` 都输出 `EMPTY`，`FIND` / `DEL` 找不到该学号时输出 `ERR NOTFOUND <id>`，命令名不在上面五条之列的输入输出 `ERR UNKNOWN`；所有非法输入都必须以错误行收尾，而不是崩溃、卡死或静默跳过，允许出现的错误行只有 `ERR INVALID`、`ERR DUPLICATE <id>`、`ERR FULL`、`ERR NOTFOUND <id>`、`ERR UNKNOWN` 五种。除上述规定的结果行以外，标准输出不得有任何其它内容（不要菜单、提示语、调试信息）。程序必须能连续处理多行直到 EOF，不得越界读写，不得调用 `system()` / `popen()` / `exec` 系列，并须能通过 `gcc -std=c11 -Wall -Wextra -O2 -o student student.c`（零错误、零警告）。

## 完整版题面（供人理解 · **不要粘给模型**）

> 本节是同一道题的**展开说明**，用途有三个：给**出题者 / 评审者**看懂这题到底考什么；
> 作为 `exam/cases/` 每个 `*.expected` 的**来源与依据**；以及**记录哪些内容被故意从题面里扣掉**。
>
> **它不是给模型看的**：下面这些条目里，除"协议"（命令名、结果行格式、五个错误词）之外的部分，
> 在「题面」一节中是**故意不写的**——那正是本题的考点（见「从题面里故意扣掉的部分」）。

### 数据模型

- 学生记录含：学号 `id`（整数）、姓名 `name`（不含空白的字符串，长度 1~15）、三门课成绩 `s1 s2 s3`（整数）。
- 平均分 = 三门课成绩之和 / 3.0，输出时保留 **1 位小数**（四舍五入）。
- 系统**最多容纳 100 名学生**。

### 命令（一行一条，命令名大写）

| 命令 | 含义 | 成功输出 | 失败输出 |
| --- | --- | --- | --- |
| `ADD <id> <name> <s1> <s2> <s3>` | 添加学生 | `OK <id>` | 见下表 |
| `FIND <id>` | 按学号查找 | `TOTAL <id> <总分> <平均分>` | `ERR NOTFOUND <id>` |
| `DEL <id>` | 按学号删除 | `OK <id>` | `ERR NOTFOUND <id>` |
| `RANK` | 打印全部学生，按平均分**从高到低**；平均分相同则按**学号从小到大** | 每个学生一行：`RANK <名次> <id> <name> <平均分>`，名次从 `1` 开始 | 一个学生也没有时输出 `EMPTY` |
| `STATS` | 统计 | `COUNT <人数> MAX <最高平均分> MIN <最低平均分>` | 一个学生也没有时输出 `EMPTY` |

### `ADD` 的失败输出（按下面的**优先级顺序**判定，命中即返回，不要继续往下判）

1. 参数个数或类型不合法（学号不是整数、三门成绩不是整数、缺参数、多参数）→ `ERR INVALID`
2. 学号、成绩**超出范围**（学号 1~99999；成绩 0~100）→ `ERR INVALID`
3. 姓名为空、长度超过 15、或含空白字符 → `ERR INVALID`
4. 该学号**已存在** → `ERR DUPLICATE <id>`
5. 学生数已达 100 → `ERR FULL`

> 顺序很重要：先判"参数合不合法"，再判"是不是重复"。例如 `ADD 1 A 101 0 0`（成绩超范围，且假设 1 已存在）必须输出 `ERR INVALID`，不是 `ERR DUPLICATE`。

### 其它规则

- 空行、以及以 `#` 开头的行**直接跳过**，不产生任何输出。
- 命令名不在上表中的 → `ERR UNKNOWN`（只输出这**一个词**，不带任何其它内容）。
- 除上表规定的结果行以外，**标准输出不得有任何别的内容**（不要打印菜单、提示语、调试信息）。
- 命令名与参数之间用**一个或多个空格**分隔，宽进严出。
- 程序必须能**连续处理多行直到 EOF**，不得在处理第一行后就退出。

### 示例

输入：

```text
ADD 1 Alice 90 90 90
ADD 2 Bob 70 80 90
FIND 1
FIND 9
RANK
STATS
```

输出：

```text
OK 1
OK 2
TOTAL 1 270 90.0
ERR NOTFOUND 9
RANK 1 1 Alice 90.0
RANK 2 2 Bob 80.0
COUNT 2 MAX 90.0 MIN 80.0
```

### 硬性要求

- 用 `gcc -std=c11 -Wall -Wextra -O2 -o student student.c` 必须**零错误**编译；
  生产代码里不得出现编译警告（警告会打印在判分报告里，供人工参考）。
- 不得越界读写（判分用例会跑到容量上限）。
- 不得调用 `system()` / `popen()` / `exec` 系列（不需要，也不允许）。

### 从题面里故意扣掉的部分

| 扣掉的内容 | 为什么扣 |
| --- | --- |
| `ADD` 失败的**判定优先级**（先合法性、再重复、再容量） | 本题最主要的考点；给了就等于给了答案 |
| 姓名 / 学号 / 成绩的**具体校验规则**（空白字符、长度上限、取值范围） | "什么叫非法"必须由模型自己界定 |
| `RANK` 的**并列名次**规则（平均分相同时按学号升序） | 属于"规格没写全时的合理默认"，考推断 |
| 容量满时**先判重复还是先判满** | 同第一条 |
| 删除后学号**可否复用** | 同上 |

**为什么这样切**：这份清单就是"从需求推出规格"这件事本身；写进题面，等于替模型做完了它，这题也就没得练了。
但**跨边界要传的字节必须给全**（命令名、结果行格式、五个错误词、`#` 注释与空行的处理）——
不给这些，判分无从进行。那属于**接口定义**，不属于提示：
判断依据是"这份规格有没有替代模型思考"——协议替代不了，判定规则可以。

## 评分标准

`bash exam/verify.sh <你的工作目录>` 会自动：

1. 用上面的命令编译 `student.c`；
2. 依次把 `exam/cases/caseN.in` 喂给程序，与 `exam/cases/caseN.expected` **逐行比对**（忽略行尾空白与文件末尾空行）；

| 判据 | 权重 | 说明 |
| --- | --- | --- |
| 编译通过 | 必须 | 编译失败则总分 0 |
| 4 个用例全通过 | 100 分 | 每个用例 25 分 |
| 编译零警告 | 加分项 | 判分报告会单独列出，供人工评定 |

- **不给部分分数**：一个用例里只要有一行对不上，该用例即 0 分（输出是严格协议，宽容会掩盖问题）。
- 判分脚本在**你的工作目录**里运行，不会修改 `student.c`；编译产物叫 `student`，与题目要求同名。
- ⚠️ **判分口径就是上面「完整版题面」**，而模型**看不到**它 ⇒ 这题的通过门槛比"照着规格实现"高一档：
  它得先自己把规格推对。这是刻意的（判据见「从题面里故意扣掉的部分」末段）。

## 关于"这题考什么"

它不是算法题。它考的是**边界条件、错误路径与协议一致性**——这正是小模型最容易漏的部分。
与早先一版的区别只有一处，但那处是本质的：**题面只给协议、不给规格**。
"什么算非法、谁先谁后、空集合怎么办、并列怎么排、满了怎么判"全部留给模型自己推
（即上面「完整版题面」里那些条目，以及「从题面里故意扣掉的部分」那张表）。

所以**人纠正模型**这件事在这题上是必答题：模型大概率会一到两轮就"看起来做完了"，
但用例会告诉你它在哪儿偷了懒。判分脚本的作用就是把人从"逐行肉眼比对"里解放出来。

> 设计变更的由来（2026-10-10）：所有者指出——原先那份多段式题面**把"读需求 → 找边界"这一步替模型做完了**，
> 而这一步恰恰是 AI coding 该考的东西；一份好的题面应当**只描述目标与协议**。
> 因此改为一句话/一段话式的「题面」，原版降级为供人理解的「完整版题面」。
